HAYATE BAY: SKYLINE ACE — a golden-hour 3D flight game over a karst canyon bay: 12 sorties + 4 bonus missions, 3 flyable jets, carrier traps, storm fronts, and the Jetstream Fever score multiplier. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Play

Pick a sortie and a jet on the mission-select cover, then press LAUNCH (or Enter). Fly with arrow keys / WASD, Shift for afterburner, Space for airbrake, G gear, F flaps, C cockpit view, V camera, 1/2/3 radio abilities, X drop crate, R retry, M mute, P pause. TRUE 6DOF: J / L strafe left / right and I / K vertical thrust up / down (or PgUp / PgDn) — independent lateral and vertical thrust without changing yaw or pitch, with the live STRF / VERT readout in the HUD. Thread the numbered rings, fly under the Dragon Bridge, trap wires on the carrier, and ride the Jetstream Fever up to ×8. `?autoplay=1` runs a demo bot; `?safe=1` lowers quality for weak machines; `window.__kazebay` exposes the debug API (setSortie, setJet, forceCrash, forceLanding, setWeather, setFever, getStats).
